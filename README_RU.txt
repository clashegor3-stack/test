RUSSIA ONLINE ANTI-AFK — Windows-приложение

Это проект нативного Windows-приложения на C#/.NET. Само приложение не требует установленного Python или .NET на компьютере пользователя: публикация собирается как self-contained single-file EXE для Windows x64.

КАК ПОЛУЧИТЬ ГОТОВЫЙ EXE ЧЕРЕЗ GITHUB:
1. Создай новый репозиторий на GitHub.
2. Загрузи в него все файлы и папку .github из этого архива (не загружай сам zip как единственный файл).
3. Открой вкладку Actions в репозитории.
4. Выбери workflow «Build Windows EXE» и нажми Run workflow. При первой загрузке workflow также может запуститься автоматически.
5. Когда сборка завершится, открой её страницу в Actions и скачай artifact «RussiaOnlineAntiAFK-Windows-x64».
6. Внутри будет RussiaOnlineAntiAFK.exe. Его можно запускать двойным щелчком.

УПРАВЛЕНИЕ:
- Зелёный индикатор — анти-AFK включён.
- Красный индикатор — выключен.
- Кнопки запуска и остановки.
- F6 — включить/выключить, F7 — закрыть.
- Можно задать клавишу W/A/S/D, интервал и длительность нажатия.

Важно:
- Это приложение отправляет обычные нажатия клавиш в активное окно. Перед запуском переключись в игру.
- Не запускай его, если персонаж может уйти с места или попасть в опасность.
- Автоматизация может нарушать правила конкретного сервера и привести к санкциям.
- Windows SmartScreen может показать предупреждение для самостоятельно собранного приложения.
