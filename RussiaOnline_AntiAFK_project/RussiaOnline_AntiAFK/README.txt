Russia Online Anti-AFK

Сборка EXE на Windows:
1. Установи Python 3.10 или новее с python.org (при установке отметь Add Python to PATH).
2. Распакуй архив в отдельную папку.
3. Запусти build_exe.bat.
4. Готовый файл появится в dist\RussiaOnlineAntiAFK.exe.

Управление:
- F6 — включить/выключить.
- F7 — закрыть программу.
- В окне можно изменить клавишу, интервал и длительность нажатия.

По умолчанию программа коротко нажимает W раз в случайный промежуток 45–65 секунд.
Перед использованием проверь правила сервера: автоматизация может быть запрещена.
Не запускай программу, если персонаж находится рядом с опасными объектами или может уйти с места.
